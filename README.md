## 这是什么

Demo 范围已定：**2 座岛**（老家 + 展示岛）+ **1–2 个职业**。
这一页要定的，是串起这两座岛的**底层循环**。

**核心结论**：两位此前的分歧（"战斗刷刷刷" vs "电影化叙事"）**不需要折中**——因为这两件事看起来在争夺同一条时间线，其实不是。

- 刷刷刷需要**可重复**的单元
- 电影化叙事需要**不可重复**的时刻
- 而**翻面**恰好两边都占：世界状态切换＝可重复（同一张地图两份内容）；灾难与抉择＝不可重复

所以四个方案的区别，本质上是：**翻面在这个循环里处于什么位置。**

---

## 怎么用

1. 打开网址，先在顶部**选身份**（程序侧 / 创作侧）
2. 给四个方案各打两个分（可玩性 / 叙事密度），并排个顺序
3. 对**合成方案**表态，并把配比调成你想要的比例
4. 往下继续填 **④⑤⑥ 三节共 12 个小决定**（每节都给了具体方案和选项）：
   - **④ 两座岛**：分工 / 老家结尾 / 岛2 可刷目标数 / 选择是否永久改变岛
   - **⑤ 职业**：1 个还是 2 个 / 技能树怎么分 / 能否中途换 / 序章主角用谁
   - **⑥ 翻面倒计时**：能否接受 / 给多长 / 归零后果 / 要不要让玩家看见
5. **每个决定都可以附一条「想法」**（选填）：选完选项后，下面会自动出现一个输入框，
   写为什么这么选、有什么顾虑、想附加什么条件。不想选也可以点「＋ 补充想法」提前写。
6. 点底部「**生成结果与回传链接**」→ 把链接发给对方
7. **对方打开你的链接后，你的答案会被锁住** —— 他必须**先自己填完**（页面会写明还差几项，
   没填的题目标着「未填」），填完之后才会自动展开，看到一致、分歧与「想法对照」

> **为什么要锁**：如果他一点开就看见你的理由，很容易被带着走，那样这一页就白填了。
> 锁到双方各自填完，对比才有意义。
>
> 两个人都填完之后，看「对方的选择」那一节就知道该优先讨论哪一项。
> **分歧最大的往往不是选项本身，而是双方在「想法」里写的理由——那里才是要谈的地方。**

## 四个方案

| | 名字 | 一句话 |
|---|---|---|
| **A** | 翻面驱动 · 远征 | 每次翻面＝一次远征，在倒计时内达成目标 |
| **B** | 航线驱动 · 航段 | 航线就是时间轴，抵达即演出（**最易做**） |
| **C** | 平衡度驱动 · 代价 | 刷得越狠，世界越接近翻面（**最能体现世界观**） |
| **D** | 日志驱动 · 记录 | 知识就是进度（**最便宜的长线目标**） |

**推荐合成**：骨架用 **B**、心脏用 **C**、长线用 **D**、高潮用 **A**。
玩家沿航线抵达一座岛 → 探索与记录 → 用战斗解决问题 → 而每次战斗都在消耗这座岛的能量 → 消耗够多，岛会翻面 → **世界记得他做过什么**。
